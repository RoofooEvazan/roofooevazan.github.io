Season 12 Suffering - November 28th 2025

Patch Notes S12

Reddit Thread)

General Changes

  • Added a button to upgrade rejuvenation potions and flawless gems directly in the stash.
    • This is a quality of life change to skip having to do cube recipes.
  • Added the ability to search items in the stash:
    • The search allows for searching ANY text contained on the item (name, stats, etc).
    • Supports regex.
    • Ctrl + F as hotkey for searching.
    • This also displays which tabs contain the searched item.
  • Shrine buffs are now removed on entering maps.
    • This was changed because people complained about the EXP shrine meta.
  • Anya now rewards 3 tier 1 maps instead of 1.
  • Increased drop chance of T1 maps in corrupted zones.
  • Increased the maximum amount of times a missile using the +% change to pierce mod could pierce from 4 to 10.
  • Split the sound options into multiple sliders for complete customization.
  • Added an "Autosync" feature to the options menu.
    • This will automatically resync the player with the server at a fixed interval if the player is desynced beyond a certain value.
  • Added an in-game command ".show-ui" that toggles showing all the UI or not.
    • Note: This is somewhat hacky and not intended for normal gameplay, it's purely for getting screen recordings without the UI. Most players will NOT want to use this.
  • Added an in-game command ".set-cursor [0-39]".
    • Note: Anything other than 0 will draw a small colored box (in various styles and colors).
    • ".set-cursor 0" will reset this.
  • Reworked melee splash:
    • It now rolls damage and checks for resistances on each monster it hits independently instead of being based on the initial target.
    • All effects applied by attacks are now carried with melee splash with the exception of "On Hit" and "On Striking" proc effects (On Hit/Striking did not apply in the previous iteration either so this has only increased the amount of effects that can be applied via splash).
  • Reduced Talic's whirlwind damage.
  • Socket recipes for normal quality items now work on arrows (arrows use the shield recipe).
  • Socket recipes now work on superior items.
  • When using the socket recipe for normal quality items on helmets, shields or chests they will now roll between 1-3 (helmets) or 1-4 (shields/chests) instead of rolling 1-6 and defaulting to the max possible socket amount when rolling above it.

Bug Fixes

  • Fixed an issue causing +% elemental damage stats from not increasing flat added elemental damage on ranged attacks.
  • Fix the crash from hovering skills while an "X skill while equipped" aura item is equipped.
  • Shadow Master is now correctly gaining strength.
  • Fixed Blade Fury animation cancelling.
  • Fixed an issue with Artic Blast and Inferno channeling.
  • Fixed Uber health overflowing in higher player counts.
  • Fixed an issue with unique/set item generation through cube recipes using the name of the item (single player mod fix).
  • Fixed a client crash for players using controller when pressing LB/L1 after joining a new game.
  • Fixed an issue with the aim assist setting not saving properly on controller.
  • Fixed some controller joysticks not fully matching the direction pushed.
  • Fixed item text flickering with long descriptions and item help text turned on.
  • Fixed an issue with Right-Click Equip sometimes getting "stuck" on cursor when equipping to an empty slot with an item that the player does not meet requirements for.
  • Added an option to turn Right Click Equip on or off.
    • Go to Esc -> Options -> PD2 Options -> Controls.
  • Fixed controller D-Pad item movement not working in stash/NPC trade until the cursor is moved.
  • Fixed a crash related to the new unique Void map.
  • Fixed an issue with resistance modifiers being calculated twice for melee splash damage.
  • Fixed an issue where maps would sometimes turn into a broken Ruined Citadel map after a cube recipe.
  • Fixed player characters sometimes displaying the incorrect items or missing their heads in the lobby screens.
  • Fixed Poison/Open Wounds damaging Uber bosses while they are immune.
  • Fixed some map bosses having the incorrect level.

Loot Filter

  • Added a new function to play drop notification sounds.

  • Added %BASENAME% keyword (thanks segnis).

  • Added REROLLALVL & %REROLLALVL% keywords (thanks segnis).

  • Added TRUE or FALSE keywords (thanks segnis).

  • Added JEWELRY, CHARM and QUIVER conditions.
  • Added BUYPRICE and %BUYPRICE%.
