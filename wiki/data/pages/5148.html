Season 7 Revelation - April 28th 2023

Patch Notes S7

Patch Notes Document (Reddit Thread)

NOTICE: Maps are being fundamentally changed this season to be stackable. Old maps will cause compatibility errors and will need to be dropped beforehand.

GENERAL CHANGES

  • Added a new act 4 mercenary which can be hired at Tyrael and uses staves
    • Dark version: Casts bone armor, Bone Spear, Teeth, Curse Mastery and Amplify Damage
    • Light Version: Casts holy bolt, fists of the heavens, holy nova and has sanctuary aura

    • Added a new act 1 physical mercenary that uses strafe, slow movement and magic arrow
    • The fire act 1 mercenary now uses exploding arrow instead of strafe
    • The cold act 1 mercenary now uses freezing arrow instead of strafe
  • Rare items have received a massive overhaul

      • Triumphant (1 mana after each kill)

  • Added a new stat "+X Open wounds damage per second"
  • Open wounds now stacks up to three times on a target
  • Open wounds now lasts 5 seconds
  • Open wounds no longer has a ½ penalty against uniques, champions or prime evils
  • Open wounds now applies from attackers take damage
  • Open wounds now applies to splash damage
  • Open Wounds in PvP now has the following adjustments:
    • Normal: 16% damage
    • Nightmare: 12% damage
    • Hell: 6% damage
  • Crushing blow now applies to splash damage
  • Added a new stat “Curse Resistance” which reduces the effect of curses against you by X%
  • Reduced Curse Duration now caps at 75%

  • Poison damage is now calculated more accurately in the DPS meter
  • Hardcore players whos deeds of valor are announced to the server will now also include the monster that slayed them
  • Slain messages will now come from a different account allowing you to mute them if you wish without blocking server messages

  • Critical Strike stat now shows the correct values on the advanced stats page
  • Mephisto in Hell difficulty can now drop Prime Evil Soul (fixed - wasn't mentioned)

MAPS

  • Added two new unique maps
    • These maps will both be diablo 1 inspired
    • Zhar’s Sanctum will have a large chance to drop charms and the boss will always drop skiller charms (Map made by Alma)
    • The Stygian Caverns will have a chance for items to drop corrupted and the boss will always drop a corrupted unique item (Made by Aerlynn)
  • Added two new map events
    • Gheed now has a chance to spawn within a map having 5 unidentified item bases available for 1 million gold each. These items will always be unique and can upgrade to exceptional or elite bases similar to gambling
    • An Altar of the Catalyst can now spawn within your map when you interact with this shrine a boss monster will spawn defeating this monster will allow you to smash the crystal on the altar granting you Catalyst Shards. Catalyst Shards can be combined with a map to add the modifier “Area contains a random event”
  • Kehjistan marketplace now provides less experience
  • White maps can now be stacked
  • Reduced chance of spawning map events for white maps by 66%.
  • Reduced chance of spawning map events for magic maps by 33%.

UBERS

  • Diablo clone and Rathma now have multiple difficulties. The base difficulty will no longer drop the Diablo clone and Rathma exclusive items however will be much easier than previously to allow more people to farm their own Anni or Tainted Worldstone Shards
  • The Diablo Clone and Rathma exclusive items will now be locked behind hard mode difficulties. In order to access the higher difficulties you will need to cube a Vex rune or higher with the Vision of Terror or Voidstone. Vex will add difficulty 1 and each higher tier of rune will be 1 difficulty higher going from 1 (vex) to 8 (zod). The drop rates of the Diablo Clone and Rathma exclusive items as well as the difficulty will increase with each difficulty increase.
  • We will be granting an aura for the first three players to defeat Difficulty 1 (Vex) and Difficulty 8 (Zod)
  • You can now break down a hellfire torch with a key to create stackable Hellfire Ashes which can be used for the Voidstone recipe
  • All Diablo Clone and Rathma summon materials drop rates have been increased
  • Monsters within phase 1 and phase 2 of Rathma have had their experience greatly reduced

PVP

  • Regular potions can no longer be used within the PvP Arena
  • Vendors within PvP Arenas will now sell PvP mana potions which cost 1 gold and can only be used within the Arenas
  • Meteor now has reduced explosion radius within PvP arenas

LOOT FILTER

  • New Features and improvements:
    • Hidden gold will now automatically be picked up
    • Added Reload Config to the in-game settings menu
    • Added EDEF which will filter Enhanced Defense
    • Added EDAM which will filter Enhanced Damage
    • Added GEMLEVEL (same as GEM)
    • Added SOCKETS (same as SOCK)
    • Added %SK#%, %OS#%, %CLSK#%, %TABSK#%, %MULTI#,#% skill value outputs
    • Added named stat value outputs (%DEF%, %LIFE%, %MFIND%, %RES%, etc.)
    • Renamed %STAT-#% to %STAT#% (now matches the input condition)
    • All valid conditions will now work with the 'between' (~) operator
    • Conditions with negative values should now work more intuitively (prior to this change, something like [REPLIFE>10] would also match items with negative Replenish Life, like Soul Drainer)
    • Items names can now use %NL%, so long as the item is identified and its quality is magic or greater
    • Added %ED%
    • Added EDEF, EDAM, FCR, AR, REPLIFE, STAT3 (vit), STAT60 (life leech), STAT62 (mana leech) to "+" condition (can be summed before evaluation)
    • Reworked PREFIX/SUFFIX/AUTOMOD to all start from ID 1. Previously the first PREFIX was 968 (Stout) but will now be 1. Likewise the first AUTOMOD (Fletcher's) was 1645 but will now be 1. This will prevent loot filters from needing updates every time a new PREFIX or SUFFIX is added
    • Color codes which were previously Glide-Only (%CORAL%, %SAGE%, %TEAL%, %LIGHT_GRAY%) will work if HD Text is enabled (fixed - wasn't mentioned)
  • Bug Fixes:
    • Fixed a bug with Enhanced Defense and Enhanced Damage sometimes returning 0
    • Fixed a bug with 1H that prevented it from filtering "hand axe"
    • Fixed a bug with EQ2 using the wrong armor group
    • Fixed a bug with EQUIPPED which caused items in the shared stash to be incorrectly considered "equipped"
    • Fixed a bug with SHOP that would sometimes cause the condition to incorrectly return true
    • Fixed a bug with GEM/GEMLEVEL that prevented unstacked flawless/perfect from filtering properly
    • Fixed an issue with MINDMG, MAXDMG, & STAT21-24 that would incorrectly filter on base min/max weapon damage instead of +min/+max damage bonuses.
    • Fixed a bug with PRICE that would cause the condition to incorrectly return false in certain cases
    • Fixed LIFE/MANA conditions
    • Fixed MAPTIER to properly allow negative values
    • Fixed issue with MAPTIER not filtering for non-map items
