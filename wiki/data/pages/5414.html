This article displays a list of common slang and abbreviations used in Project Diablo 2 and Diablo II: Lord of Destruction.

See also Glossary.

Colors

  • Blue = Magic Item Type / Cold Damage Type / Sapphire
  • Dark Gray = Ethereal Item Type / Normal Socketed Item Type / Skull
  • Gold = Unique Item Type / Runeword Item Type
  • Green = Set Item Type / Poison Damage Type / Emerald
  • Orange = Crafted Item Type / Magic Damage Type
  • Red = Corrupted Item Type / Fire Damage Type / Ruby
  • Purple = Amethyst
  • Yellow = Rare Item Type / Lightning Damage Type / Topaz
  • White = Normal Item Type / Physical Damage Type / Diamond

#

  • 4: Used as a substitute as "For" when chatting casually (ex: "Rushing 4 Forge" equals "Rushing For Forge").
  • 8: Can be used as a substitute for "Eight"-sounding consonants (ex: "W8" equals "Wait").

Symbol

  • ?: Unidentified Item
  • ¹: Normal Base
  • ²: Exceptional Base
  • ³: Elite Base

A

  • A#: Act number (ex: A1 = Act 1)
  • AFK: Away From Keyboard
  • alvl: affix level
  • Amp: Amplify Damage
  • Ama: Amazon / Ask Me Anything
  • Ammy/Amu: Amulet
  • Andy: Andariel
  • Anni/Anny: Annihilus
  • AoE: Area of Effect
  • Arach: Arachnid Mesh
  • ASN: Assassin
  • Azn: Amazon

B

  • Barb: Barbarian
  • Bear: Druid's Werebear form or skill/oskill.
  • Bearzon: An Amazon build based on the Beast Runeword.
  • BIN: Used on tradesite for "Buy it now"
  • Blizz: Blizzard, can also refer to Blizzard Entertainment
  • BO: Battle Orders
  • BoS: Burst of Speed
  • BotD: Breath of the Dying Runeword
  • BP: Breakpoint, thresholds that govern certain character modifiers.
  • BRB: Be Right Back

C

  • C: Cold
  • ©: Copyright
  • Cap: Maximum or Limit or Ceiling
  • CB: Crushing Blow
  • CBF: Cannot Be Frozen, meaning the character cannot be frozen by most cold attacks.
  • Chat Gem: It does nothing.
  • CoS: Cloak of Shadows
  • CLS: Chain Lightning Sentry
  • clvl: Character Level
  • CS: Chaos Sanctuary or Critical Strike or Crystal Sword or Colossus Sword
  • CTA: Call to Arms Runeword
  • Cube: Horadric Cube, an item that allows you to combine items stored inside of it. Can refer to storing something in the cube or doing a recipe with the cube.

D

  • D2: Diablo II
  • Dam: Damage
  • Decrep: Decrepify
  • DEX: Dexterity
  • DMG: Damage
  • DS: Deadly Strike

E

  • ED: Enhanced Damage
  • Essence: See Token

F

  • F: Fire or the button you press to pay your respects when something unfortunate happens.
  • FBR: Faster Block Rate, which reduces the amount of animation frames the character performs when blocking once it reaches set class breakpoints.
  • FCR: Faster Cast Rate, which reduces the amount of animation frames the character performs when casting once it reaches set class breakpoints.
  • F. [Gem]: Flawless [Gem]
  • FHR: Faster Hit Recovery, which reduces the amount of animation frames the character performs when staggered by a hit once it reaches set class breakpoints.
  • FoH: Fist of the Heavens
  • FPS: Frames Per Second
  • Frame: Frame or frames in the context of action/animation timings
  • FRW: Faster Run/Walk

G

  • GF: Gold Find or % Extra Gold From Monsters or The Grandfather or Girlfriend
  • GG: Godly Gear or Good Game depending on context.
  • Gheed: Gheed's Fortune or Gheed (NPC/Map Event)
  • GL: Good Luck

H

  • HC: Hardcore, characters created with this trait die permanently
  • HF: Have Fun
  • HFD: Half Freeze Duration, wearing two or more items with this attribute effectively becomes "Cannot be Frozen".
  • HP: Hitpoint aka Life
  • HR: High Rune. These are considered to be the rarest and most valuable runes and used as currency.

I

  • IAS: Increased Attack Speed
  • ID: Identify / Identifier
  • ilvl: Item Level
  • Imbue: Horadric Hammer quest reward, from Charsi in Act 1.
  • Immune: Monster invulnerable to one or more damage types (physical, magic, fire, cold, lightning or poison).

J

  • Jalal's: Jalal's Mane
  • Juv/Juvie: Full Rejuvenation Potion

K

  • KB: Knockback

L

  • L: Lightning
  • Ladder: Designates a character trait made specifically for a recurring seasonal event where people compete to raise their character from level 1 to level 99 as fast as possible to secure a spot on a leaderboard. Ladder status is removed from pre-existing characters when a new season starts. There is a separate Ladder for Softcore and Hardcore.
  • LAEK: Life After Each Kill
  • Leech: Steal
  • Lidless: Lidless Wall
  • Light: Lightning
  • LK: Lower Kurast, but doesn't really see much use since the super chests have been removed
  • LL: Life Leech / Life Stolen Per Hit
  • LLD: Low-Level Duel
  • LoD: Lord of Destruction (Usually specifically referring to the unmodded, unremastered release of Diablo II)
  • LoS: Line of Sight, a requirement for some skills to be able to cast.
  • LPK: Life Per Kill
  • LR: Lower Resist
  • Lvl: Level

M

  • MA: Martial Arts
  • MAEK: Mana After Each Kill
  • Max: Maximum
  • MaxDMG: Maximum Damage
  • MB: Mind Blast
  • MDPL: Maximum Damage Per Level
  • Merc: Mercenary
  • Meph: Mephisto
  • MF: Magic Find / Increased Chance to Find Magic Items
  • Min: Minimum
  • MinDMG: Minimum Damage
  • ML: Mana Leech / Mana Stolen Per Hit
  • Mod: Moderator / Game Modification / Item Modifier
  • MP: Mana Point / Mana
  • MPK: Mana Per Kill
  • Mule: Character used only to store items

N

  • N: Need (when used in a public game name or trade chat)
  • Naj's: Piece of Naj's Ancient Vestige Set
  • Nat's: Piece of Natalya's Odium Set
  • Nec: Necromancer
  • Necro: Necromancer
  • NM: Nightmare Difficulty

O

  • O: Used by some item filters to refer to gems. The color of the text usually indicates which gem. / Offer (when used in a public game name or trade chat)
  • OBO: Used on tradesite for "Or best Offer"
  • OS: Open Socket
  • Oskill: A skill granted by an item that can be used regardless of class.
  • Off Aura: Offensive Auras

P

  • Pally: Paladin
  • PD2: Project Diablo 2 (this mod)
  • PDR: Physical Damage Reduction
  • PGem: Perfect Gem
  • P. [Gem]: Perfect [Gem]
  • Pierce: Either projectile penetration or ignoring partially an enemy's resistance to something.
  • P: Poison
  • Ph: Physical
  • Phys: Physical
  • PSN: Poison
  • PLR: Poison Length Reduced By %
  • PvP: Player versus Player

Q

  • qlvl: Quality Level

R

  • Req: Requirement / Requirements -%
  • Res: Resistance
  • RNG: Randomly Generated Number / Luck
  • Rush: A higher level character getting a lower level character through the story acts faster than leveling normally allows.
  • Rusher: Someone that provides rush services. See Rush.
  • Rushing: Performing a rush. See Rush.
  • Rush 4 Forge: Rush For Forge. A higher level character getting a lower level character through the story acts faster than leveling normally allows as a service. The service is paid for by leaving the Hellforge quest drops for the rusher character.

S

  • S#: Season number (ex: S11 = Season 11)
  • Script: Game Description field (when used in a public game name, sometimes shortened further to scrp, scrip, etc.)
  • Season: See Ladder or Season.
  • SC: Softcore
  • SD: Shadow Disciplines
  • Shako: Harlequin Crest
  • Sin: Assassin
  • Skiller: Grand Charm with +1 to a Class Skill Tree.
  • Sks: Skills
  • SKW: Raise Skeleton Warrior
  • Slam: Corrupting an item.
  • SoJ: Stone of Jordan
  • SoH: Standard of Heroes
  • Sorc: Sorceress
  • STR: Strength
  • Summonzon: An Amazon build focused on Decoy and Valkyrie.
  • SWb: Shock Web

T

  • t4t: Thanks For Trade
  • Tal's: Piece of Tal Rasha's Wrappings Set
  • TC: Treasure Class, which is used to determine the item pool for item drops.
  • ™: Trademark
  • Token: Token of Absolution
  • Torch: Hellfire Torch
  • ToS: Terms of Service / Rules
  • TP: Town Portal / Teleport
  • TTH: Teeth
  • TWSS: Tainted Worldstone Shard
  • Ty: Thank You

U

  • Ubers: See Ubers
  • UT: Uber Tristram

V

  • VENG: For Vengeance Paladin build (item filter).
  • VIT: Vitality

W

  • W8: Wait
  • WC: War Cry
  • Weap: Weapon
  • WoF: Wake of Fire
  • WP: Waypoint
  • WSM: Weapon Speed Modifier or Base Weapon Speed
  • WSS: Worldstone Shard
  • WTF: What The Fuck
  • WTH: What The Hell
  • WW: Whirlwind or Werewolf depending on context.
  • WWS: Witchwild String

X

  • Xbow: Crossbow.

Y

Z

  • Zon: Amazon
