Mini Crafters League - February 9th 2024

Notes

Mini Crafters League - will begin February 9 10am PST

  • Uniques, sets, and runewords are disabled during the league
    • Hellfire Torch, Annihilus and Gheeds charms are exceptions and will still drop
    • For non-ladder or single player, if you already had these they are fine, but no new uniques, sets, or runewords can be dropped or created
  • Breaking a jewel now results in 4 jewel fragments
  • Cubing 3 Flawless gems now results in 2 Perfect gems
  • Monsters in Hell grant 200% experience
  • Ubers materials such as Voidstones, Visions of Terror and Pandemonium Event Keys are now sold at Anya
  • Respec Tokens are now sold at Akara
  • Crafting infusions are a new type of item that drop from Treasure Fallen and can be used to craft with. For each type of craft there is one infusion. E.g. Blood Craft Infusion, Vampiric Craft Infusion, etc.
    • Only an infusion and the base item you want to craft with are required
  • Treasure Fallen roam the overworld and can spawn in any LOD zone in any difficulty with better loot in higher difficulties
    • Treasure Fallen run ~17% slower
    • Treasure Fallen loot table has been increased.
      • In Normal, they can drop runes up to Thul
      • In Nightmare, they can drop runes up to Lem
      • In Hell, they can drop runes up to Ist
      • Treasure Fallen now drop crafting infusions
  • Rathma/Diablo Clone Tier 1 and Tier 2 difficulty increase has been reduced by ~50% for crafting league
  • Rathma no longer spawns purely random void knights. It follows a consistent pattern;
    • 70% HP: 1 Cold, 2 Fire, 1 Poison
    • 50% HP: 1 Cold, 1 Fire, 2 Poison, 1 Physical
    • 30% HP: 2 Cold, 2 Fire, 1 Poison, 1 Physical
  • Crafting-league recipes to upgrade uber ingredient Tiers are as follows:
    • Vision of Terror + Key = +1 difficulty
    • Voidstone + Key = +1 difficulty
  • Annihilus and Hellfire Torch will still drop from their respective encounters
  • Unique maps are disabled
  • Gheed event in maps is disabled

Fixes and miscellaneous

  • You can now .roll for specific things by typing .roll <message>. This will show:“PlayerName has rolled 1 for Ber Rune”
    • You can now also type .r <message> as an alias for .roll <message>
  • “It’s locked” sound effect plays if you try to change equipment while you’ve locked it
  • Charge was improved/fixed further
  • You can once again use potions during Charge
  • Open Wounds no longer gets reduced twice by enemy physical resistance (fixed)

League Patch #1 (2024-02-10)

  • Fixed the client crash when opening the mercenary hiring page
  • Fixed an issue with the treasure fallen not dropping the full amount when killed too quickly
  • Reduced the drops slightly of treasure fallen in hell mode
  • Fixed a few bugs to help with server stability

League Patch #2 (2024-02-15)

  • Fixed an issue that prevented the 200% experience bonus in hell from applying
  • Increased the spawn rate of Treasure Fallen in LoD zones (about twice as likely)
  • Increased the chance of a map event being a treasure fallen event
    • This was done by replacing the chance for Gheed event and the uber key event with Treasure Fallen (so Treasure Fallen is 3x more likely than other events)
    • The Uber key event will no longer spawn due to the above
  • Increased the base chance for map events from 33% -> 66%
  • Increased the rune and crafting infusion drop rates on treasure fallen in Hell
  • Added Larzuk's Puzzlepiece as a drop from treasure fallen in Hell
  • Changed the jewel -> jewel fragments recipe to produce 3 jewel fragments per jewel (the 4 fragments was unintentional but it was breaking the recipe with a full cube of jewels)
  • Added new recipes for crafting league only to recycle crafted items:
    • Any crafted item + a rune from Ko -> Pul will revert the crafted item to a magic item which can be crafted again
    • The item level of the recycled item will be reduced by a percentage based on the rune:
      • Ko + Crafted item -> Magic Item with 70% item level
      • Fal + Crafted item -> Magic Item with 80% item level
      • Lem + Crafted item -> Magic Item with 90% item level
      • Pul + Crafted item -> Magic Item with 100% item level


Season 8 Depravity - September 22nd 2023

Patch Notes S8

Patch Notes Document (Reddit Thread)

NOTICE: Items with +X Open Wounds Damage per Second are being fundamentally changed this season. Old versions will cause compatibility errors and will need to be dropped or converted in singleplayer.

GENERAL CHANGES

  • Added a new mechanic called "Corrupted Zones"
    • Any game that was hosted with the baal quest complete will have a "Corrupted Zone"
    • These zones will have an area level of 85 and a much greater chance to drop worldstone shards
    • The zone chosen on game creation will change every 15 minutes and will be server wide (An already created game will not have it's Corrupted Zone changed and will require creating a new game to do so)
  • Crushing blow has been reworked to work at full value against regular monsters and bosses. Prime evils will have an aggressive diminishing return however crushing blow will still function all the way to 0% health
  • Reworked throwing potions
    • Throwing potions will now reduce enemies resistances for a short period
    • Two new types of throwing potions have been added for the cold and light elements
  • Added the ability to lock your equipment and charm slots
  • Updated to the newest version of D2GL (Made by Bayaraa)
    • This should fix issues for AMD users
  • Added a new help screen that can be found by pressing H in game
  • Added the ability to infuse a map orb or a stack of map orbs by combining the ingredients with them (This allows you to use just the infused orb alongside a map to complete the recipe)
  • Enabled the recipe to reroll 2 white arrows into a white bolt or vice versa
  • Shrine buffs will now be provided to all allies within proximity
  • Your most recent messages will now be kept within your chat log (L) even when swapping between games
    • When making player reports please include any associated chat logs
  • Fixed mercenaries not activating multiple auras when you change equipment
  • Added a new belt status feature that allows you to monitor the items within your belt
  • The unique TP/ID tomes (Horadric Almanac & Horadric Navigator) now have a very low chance of dropping anywhere (fixed - wasn't mentioned)
