This is an unlisted page that is transcluded on Item Filtering.


Formal Definition

Formulas can be defined anywhere in the loot filter using Formula[KEY]: FORMULA. References to a formula must be in the form of FORMULAKEY. Formula[_A]: STAT1!=STAT2 can be referenced by FORMULA_A or %FORMULA_A%.

Only '_' or 'A' to 'Z' may be used in a formula's key.

Aliases cannot be used in the definition.

Inline Definition

An inline formula definition is a formula inside a block $f(STAT1!=STAT2). The 'f' must be lowercase and parentheses must match.

Aliases can be used in the definition.

Item Input

A formula can be used as a boolean, value or a part of an add condition.

condition description
ItemDisplay[$f(STAT1+STAT2)>25] value comparison
ItemDisplay[$f(STAT1+STAT2>20)] boolean condition
ItemDisplay[$f(STAT1)+STAT2>15] add condition

The "truthiness" of a formula is based on a value being NOT equal to zero.

formula description
1.5 true, since 1.5 != 0
TRUE true, since TRUE (1) != 0
FALSE false, since FALSE (0) == 0
0 false, since 0 == 0
.0000001 true, x != 0

Item Output

The result of a formula is a real number. It is rendered with either 0-2 decimal places depending on the fractional part with two decimal places. If a math error occurs or the value is too large to be rendered, the text is f_err. The maximum absolute value of a renderable result is 2^31 (2147483648).

1.495 1.50 1.5

Operators

==, >, <, !=, >=, <=, +, -, *, /, ^, !

Variables

All variables are case-insensitive. Each variable mirrors the code used in input or output.

Minor Details

Tidbits that may or may not change.

  • AND and OR are short-circuited
  • constant expressions such as POW(3,3) or IF(TRUE,STAT1,STAT2) are evaluated once
  • an input reference only requires the first letter (F) to be capitalized the rest is case-insensitive
  • an output reference is always case-insensitive
